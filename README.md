# Hearth and Home

![image](https://github.com/user-attachments/assets/461f3393-afca-4634-bca1-7f6725bd3574) 

Custom fork of [Secrets of Sosaria](https://github.com/Secrets-of-Sosaria/World) for personal use.

## Setup

* Copy `Saves.example` to `Saves`
* Copy `Data/System/Source/bin/Debug/World.exe` to parent directory
* Launch `World.exe`

Settings file is already pre-configured for **Hearth and Home** cozy & casual play.
